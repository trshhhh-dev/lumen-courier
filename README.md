Lumen Courier is an original neon arena courier game: pilot a prism ship through the rift, scoop aurora cores, dodge storm shards and Rift Wardens, chain combos across sectors, and relaunch after signal loss. Keyboard + mouse, offline static files, procedural audio.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
